# 城市像素领地战 视频生成器

依赖：Python3 + numpy + pillow，系统需有 ffmpeg 和中文字体 fonts-noto-cjk（脚本里用的是 `/usr/share/fonts/opentype/noto/NotoSansCJK-Bold.ttc`，路径不同时改 `FONT`）。

## 运行
```bash
python3 pixel_war.py                 # 筛选 30 个种子，渲染最有戏剧性的一局 -> sample.mp4 + preview.png
python3 pixel_war.py --seed 22       # 直接渲染指定种子
python3 pixel_war.py --horizontal --out h.mp4 --preview h.png   # 横屏 1920x1080
```

## 参数
- `--seeds N` / `--seed-start S`：候选种子数量与起点（默认 30 个，从 1 开始）
- `--teams N`：队伍数 2-8
- `--duration 秒`：对战最长时长（另加约 2 秒冠军画面；超时则按占地最多者“称霸”）
- `--no-audio`：不加音效
- `--out` / `--preview`：输出路径

## 改队伍 / 规则
- 修改 `TEAMS` 列表（城市名 + RGB 颜色）。
- `simulate()` 里：`爆发` 概率 `0.012`、倍率 `3.0`、持续 `45` 回合；`aggro` 控制扩张速度；`under`（前期弱者加成）和 `momentum`（后期强者滚雪球）决定节奏。
- `drama_score()`：领先易主次数、冠军逆袭（最低排名）、后期胶着度、是否统一、时长合适 加权打分。

## marble_war.py —— 球球领土战争（MarblePi 风格，横屏）

参考 B站/抖音「球球派MarblePi」《【百万像素+海量粒子】球球领土战争》的画面布局，规则为自行实现：

- **左侧弹珠台**：4 队弹珠（红/蓝/绿/黄，球上显示弹药量）穿过钉阵；中层槽 `x2 x8 x4 x2 闸门 x2 x4 x8 x2` 放大该队弹药，落入中央「闸门」则进入下层，落到武器槽 `霰弹 / 机枪 / 护盾 / 大球 / 狙击` 获得 4~6 秒技能。槽位下方显示命中次数。
- **右侧地图**：1000×1000（100 万像素）带浅色网格，初始四象限。四角圆形基地 + 旋转炮管，显示弹药（K/M/B）和领土%；炮台发射海量粒子（同屏上限 3 万），撞到异色像素即染色、可能反弹或钻入。
- **淘汰**：基地中心像素被敌方染色 → 淘汰，领土与一半弹药归占领者；最后存活者获胜（54 秒仍未结束则按领土判定）。
- 自动筛选种子（时长 42~56 秒且自然结束、领先易主、技能次数多、淘汰不能太早），音效为程序合成（染色滴答声限频、倍率/技能/淘汰/胜利音）。

```bash
pip install --break-system-packages numba   # numpy pillow ffmpeg 也需要
python3 marble_war.py --seeds 24            # 筛选 24 个种子后渲染最佳 (~3 分钟筛选 + ~80 秒渲染)
python3 marble_war.py --seed 1 --episode 2  # 指定种子 / 集数
```

输出：`marble_sample.mp4`（1920x1080 30fps H.264 yuv420p + AAC，约 55 秒、约 40MB）、`marble_preview.png` 及 `marble_preview_f*.png / _end.png` 关键帧。

## marble_war_v2.py —— 粒子领地大战（v2，原创系列，横屏 1920x1080）

全新原创品牌「粒子领地大战」+ 霓虹深蓝 UI 和自有配色，不再沿用参考视频的布局。v1 `marble_war.py` 保留不变。

**画面布局**
- 中间：960×960 领土地图，初始按 Voronoi 分区（边界带扰动），每队基地放在 Voronoi 站点上（不是四角）。
- 两侧：**每队一条独立弹珠竖道**（迷你 Plinko，钉阵 + 底部槽位 `x2 / 升级 / x5 / 武器 / x3`，不定时出现闪烁的 `x10` 大奖槽）。基地在左半边的队伍放左侧，右半边的放右侧。
- 竖道顶部实时显示：队名/队色、弹药（K/M/B）、炮台等级 + 形态、等级进度条、当前武器/护盾倒计时、领地 %。
- 顶栏：系列名 + 集数、领地占比条、阶段（发育期 / 混战期 / 决战期）与计时。

**炮台成长 Lv1-5**：单发 → 散射（3 管）→ 连射 → 激光（周期性光束直线涂色）→ 导弹 + 终极炮（全向爆发 + 全屏闪光）。
升级来源：升级槽、x10 大奖、攻破敌方基地（+2）、击破 Boss（+2）。等级越高底座越大、光晕越强，Lv3+ 有旋转光环。
升级时：横幅「红队 升级 Lv.3！」、冲击波环、粒子爆发、屏幕震动、音效。

**戏剧性/平衡**
- 橡皮筋：领地低于平均的队伍弹药收入更高、火力更强，弹珠更容易被“吸”向 x5/升级/大奖槽，大奖也更常出现在弱队。
- 围剿：混战期起，领先者领地 > 26% 且是第二名 1.4 倍时，触发 8 秒「围剿」，其他队全部集火领先者。
- 随机事件：陨石（优先砸领先者，坑变为中立灰）、清屏炸弹、中立 Boss（被击破者获得 8 倍弹药，Boss 周期性震荡波）、决战期毒圈收缩。
- 开局约 12 秒基地保护，决战期淘汰阈值更低，让淘汰分布在中后段。
- 弹药为“收入 × 时间指数增长 − 按比例消耗”，加上倍率槽冲击，数字一直在跳，不会卡在上限；发射量按 log10(弹药) 计算。
- 种子筛选打分：领先易主次数、绝地反击次数、淘汰数量与间隔均匀度、末段前两名接近程度，惩罚过早淘汰 / 中期一家独大。多进程并行筛选（30 个种子约 30 秒）。

**特效**：粒子拖尾（衰减缓冲）+ 降采样模糊的加色辉光、浅色粒子芯 + 深色描边、命中火花、基地爆炸碎片与冲击波、领地渐变归属征服者、屏幕震动、大事件慢动作、终极炮/清屏全屏闪光、中文实时解说字幕（「蓝队绝地反击！」「金队被围剿！」…）。
**音效**全部程序合成：限频命中声、槽位声、升级琶音、爆炸、激光、警报、120BPM 背景鼓点（决战期加贝斯）、胜利小调。

```bash
python3 marble_war_v2.py                          # 6 队，筛选 30 个种子后渲染最佳（约 30 秒筛选 + 约 5 分钟渲染）
python3 marble_war_v2.py --seed 9                 # 直接渲染指定种子
python3 marble_war_v2.py --teams 8 --seeds 40     # 4-8 队
python3 marble_war_v2.py --duration 80 --episode 2 --out ep2.mp4 --preview ep2_preview
```
参数：`--teams`（4-8，默认 6）、`--seeds` / `--seed-start`（筛选数量与起点）、`--seed`、`--duration`（对战秒数，默认 72，另加约 4 秒冠军画面）、`--episode`、`--jobs`（并行进程）、`--out`、`--preview`（关键帧 PNG 前缀）。
暂不支持竖屏（`--vertical` 未实现）。

输出：`marble_v2_sample.mp4`（1920x1080 30fps H.264 yuv420p + AAC，约 79 秒，约 62MB），以及 `marble_v2_preview_*.png` 关键帧。

## marble_war_v3.py —— 粒子领地大战 v3（10 分钟长篇版，横屏 1920x1080）

v2 反馈：“节奏太快、太短，想要 10 分钟；弹珠道全部放左边，2 行 x 3 列，底部多放技能槽；越强的技能槽越窄”。v2 保留不变。

**画面布局**
- 左侧：每队一块 Plinko 弹珠台，按 2 行 × N 列排布（4 队 2×2、5-6 队 2×3、7-8 队 2×4）。
  每块顶部是队伍面板：队名 / 弹药（K/M/B）/ 炮台等级+形态 / 领地% / 等级进度格（8 格）/ 当前武器·护盾·冰冻倒计时。
- 右侧：960×960 领土地图（Voronoi 初始分区）。
- 顶栏：系列名 + 集数、当前阶段、`mm:ss / 10:00` 计时 + 阶段进度条、领地占比条、存活队伍数。

**技能槽（16 种，槽宽与价值成反比）**
- 普通（最宽，约 34-46px）：`x2` `x3` `散射` `机枪` `护盾` `修复`（修复基地周围领土 + 3 秒护盾）
- 中级（约 29-33px）：`x5` `升级` `大球` `狙击` `导弹`（8 轮重型导弹射向目标基地）`激光`（立即发射 1.5 秒激光）
- 稀有（最窄，约 21-24px，比弹珠只宽一点）：`冰冻`（冰冻当前最强敌人 6 秒，停火）`援军`（4 秒援军火力）`x10`（弹药 x10 + 升级点）`终极`（全向 2200 粒子爆发 + 激光）
- 每块板子按宽度抽取普通/中级/稀有槽（`升级` 必定在场），**每进入新阶段槽位重新洗牌**。槽位按稀有度用不同底色与描边，窄槽文字竖排（≥18px）。
- 每颗弹珠头顶实时显示本队弹药量（如 `4.2K` `1.2M`，18px 粗体描边），弹珠直径 18px。
- 弹珠落入时：槽位高亮闪烁并上弹、弹出“+x5 / 升级! / 激光!”结果标签（放大后上浮淡出）、基地处爆出技能色粒子；稀有技能另有横幅和音效。

**节奏（默认 600 秒，`--duration` 可改，所有时间按比例缩放）**
- 四个阶段 + 阶段标题卡：发育期 0:00-1:42（基地保护 1:45）→ 扩张期 → 混战期（3:48 起）→ 决战期（7:00 起）。
- 炮台 Lv1-8：单管 → 双管 → 散射 → 连射 → 激光 → 导弹 → 双激光(更快更粗) → 终极（周期性全向爆发）；升级所需点数逐级增加（2/3/3/4/4/5/6）。
- 弹药增长更慢（时间指数 1/160），火力强度随时间线性提升；基地“自愈”随时间减弱，终局（最后 10%）防御失效、火力 x1.3。
- 每次有队伍出局，所有存活基地获得 35 秒“余波护盾”，避免淘汰扎堆。
- 循环事件：围剿领先者（冷却 24 秒）、陨石（每 18-30 秒，决战期更频繁）、3 波 Boss（2:30 / 5:00 / 7:25，90 秒未击破则撤退）、2 次清屏炸弹（约 4:15、6:35）、冰冻 / 援军 / 终极技能。
- 决战期 7:48 起毒圈收缩：圈心从地图中心移向当时前两名基地的中点，最终只剩容纳两座基地的小圈 → 大概率打到一队统一，否则按领地判定。

**种子筛选**：多进程 headless 全程模拟（全分辨率，每个种子约 30-40 秒；8 进程筛 24 个约 2 分钟），
打分项：领先易主、绝地反击、淘汰数量与间隔均匀度、首个淘汰落在 2-4 分钟、是否一队统一且结束得晚、最后两分钟仍有对决、末段前两名接近程度；惩罚中期一家独大、过早满级。

**渲染**：约 10 fps（numba 粒子/特效 + PIL 文字），ffmpeg `libx264 -preset veryfast -crf 23 -maxrate 4.2M`，10 分钟约 30 分钟渲染、体积 < 400MB；
每 600 帧写一行进度到日志。音频全程程序合成，背景鼓点按阶段变化（92 → 108 → 124 → 140 BPM，混战期加贝斯，决战期加高音点缀）。
另外自动剪一个约 60 秒的高光预告（开场 + 淘汰 / Boss / 终极 / 毒圈等关键时刻 + 结局）。

```bash
nohup python3 marble_war_v3.py --seeds 24 > render_v3.log 2>&1 &   # 筛选 24 个种子 + 渲染最佳 + 预告
python3 marble_war_v3.py --screen-only --seeds 40                  # 只筛选种子
python3 marble_war_v3.py --seed 15                                 # 直接渲染指定种子
python3 marble_war_v3.py --teams 8 --duration 480 --episode 3 --out ep3.mp4 --preview ep3_preview
```
参数：`--teams`（4-8）、`--seeds` / `--seed-start`、`--seed`、`--duration`（秒，默认 600）、`--episode`、`--jobs`、`--screen-only`、`--no-trailer`、`--out`、`--preview`、`--trailer`。

输出：`marble_v3_sample.mp4`（1920x1080 30fps H.264 + AAC）、`marble_v3_trailer.mp4`（约 60 秒高光）、`marble_v3_preview_XX_时间.png`（10 张时间轴关键帧）+ `marble_v3_preview_end.png`。

## marble_war_v5_demo.py —— 粒子领地大战 v5（约 10s 机制演示）

```bash
pip install --break-system-packages pymunk
python3 marble_war_v5_demo.py   # -> marble_v5_demo.mp4 + marble_v5_demo_preview_*.png
```
